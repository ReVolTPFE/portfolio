# DevDocs - Documentation Dynamique

DevDocs est un site de documentation généré dynamiquement grâce à **Nuxt Content**. Il est conçu pour structurer des documents techniques et API en toute simplicité.

## Fonctionnalités
- Génération automatique des pages à partir de fichiers Markdown
- Navigation rapide et intuitive
- Intégration facile avec VueUse pour une meilleure interactivité
